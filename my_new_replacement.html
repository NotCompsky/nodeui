Guide/Options

NOTE: Loops don't work as expected. But if the execution chain (yellow circles) is linear, it should work flawlessly.

Add new node by clicking on an empty space; or click+drag from a circle to restrict options to relevant nodes

Zoom with mouse (this replaces scrolling etc because I am lazy)

To detach edge: Click and drag from one connection to the other (same action as creating an edge)

To delete node: Not implemented yet

Looping: All circles can only have one input into them, except execution circles which can have limitless.

NOTE for developer of this program: Any node that has a state-affecting action should be in the execution flow, so that its action is executed in the correct order.
