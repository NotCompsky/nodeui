Intended purpose: to be a **tiny** JavaScript script to allow non-engineers to create **rudimentary** workflows in an intuitive way. For example, for a user to define a custom search filter on a website.

It is not intended to be used for serious programming projects. Plenty of developer-oriented visual programming tools exist for that.

Currently, it is probably riddled with bugs. Loops don't yet work.

# Usage

Download the 3 files (HTML, JS and CSS) and open the HTML in your browser.
